# Kia Motors Sales & Business Analytics

## Project Overview
This project focuses on analyzing Kia Motors sales and business data using SQL queries.

## Analysis Areas
- Customer Analysis
- Vehicle Analysis
- Dealership Analysis
- Sales & Revenue Analysis
- Employee Analysis
- Payment Analysis
- Service Analysis

## Tools Used
- SQL
- Relational Database Queries

## Project Work
This project contains 50 SQL questions and queries designed to explore business performance and generate meaningful insights.

## Learning Outcomes
- Practiced SQL queries for business analysis
- Worked with joins, aggregate functions, subqueries, and grouping
- Explored sales, customer, dealership, and service data
